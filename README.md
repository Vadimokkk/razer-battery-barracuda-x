# Razer Battery

**Индикатор заряда Razer Barracuda X для Windows.** Приложение работает в трее и не требует Razer Synapse.

[Скачать готовый архив](https://github.com/Vadimokkk/razer-battery-barracuda-x/releases/latest/download/RazerBattery-Windows.zip) · [Скачать exe](https://github.com/Vadimokkk/razer-battery-barracuda-x/releases/latest/download/RazerBattery.exe)

## Возможности

- Заряд в системном трее и автоматическое обновление.
- Подключение через USB-донгл 2,4 ГГц и Bluetooth Windows.
- Панель с круговым индикатором, оценкой оставшегося времени и расхода.
- История заряда за 24 часа и 7 дней. Замеры сохраняются локально до 30 дней.
- Индикация зарядки и уровень батареи во время зарядки.
- Время работы и расход рассчитываются по сохранённым замерам разряда.
- Напоминания о низком заряде, автозапуск Windows и ручное обновление.
- Переключение микрофона Windows по умолчанию из меню значка трея.

## Подключение и точность

- С донглом `1532:0550` приложение получает от гарнитуры точный процент и состояние зарядки. Подключение кабеля больше не переводит напряжение аккумулятора в ложный скачок процента. Для `1532:0552` приложение запрашивает процент и состояние кабеля напрямую.
- Если гарнитура ещё не прислала точный процент, приложение временно показывает последний известный уровень или примерную оценку по напряжению.
- На `1532:0550` зарядка обозначает состояние, сообщённое самой гарнитурой; на `1532:0552` отображается подключение зарядного кабеля.
- По Bluetooth отображается процент, который сообщает Windows.
- История начинается собираться при первом запуске приложения и появлении доступного замера; данные за прошлое время не восстанавливаются.
- Оценка расхода и оставшегося времени появляется после минимум 10 минут и снижения уровня на 2%; приложение использует до 6 часов локальных замеров.
- Микрофон переключается на уровне Windows для устройства записи по умолчанию. Это не команда микрофону через донгл.
- USB-C кабель зарядки сам по себе не передаёт компьютеру заряд батареи. Аналоговый кабель 3,5 мм также не передаёт эти данные.

## Сборка из исходников

На 64-разрядной Windows открой PowerShell в папке репозитория и запусти:

```powershell
.\build.ps1
```

Сборка использует компилятор .NET Framework, поставляемый с Windows. Версионный exe и `RazerBattery-Windows.zip` появятся в `dist/`.

GitHub Actions автоматически собирает архив при изменении ветки `main`. Чтобы опубликовать релиз, создай тег вида `v1.3.1` и отправь его в репозиторий: workflow соберёт exe и прикрепит архив к релизу.

## Если донгл не читается

Включи гарнитуру и подключи её в режиме 2,4 ГГц. Если Windows запрещает доступ к донглу, закрой Synapse. Если это не поможет, запусти приложение от имени администратора.
